# CampusPulse Project Statement

## Project Title

CampusPulse - Campus Operations and Intelligence Platform

## Problem Statement

College students and campus staff deal with different types of information such as maintenance issues, mess feedback, library books, and facility status. Managing these separately can make information difficult to track.

CampusPulse brings these basic campus operations together in one Java application.

## Objective

The objective of this project is to develop a simple campus management system using Java and MySQL. The application allows users to store, manage, and view campus-related information while also providing basic analytics and an interactive rule-based assistant.

## Main Modules

1. Issue Management
2. Mess Management
3. Library Management
4. Facilities Management
5. Analytics
6. Campus Assistant - Pulse

## Technologies

Java, JDK 27, Maven, MySQL, JDBC, and MySQL Connector/J.

## Expected Outcome

The completed system provides a functional console-based application where campus records can be added, viewed, updated, deleted, and analyzed through a single interface.

## Conclusion

CampusPulse demonstrates how Java programming and database connectivity can be used to build a practical application for managing common campus operations.
